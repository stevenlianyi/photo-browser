# ⚠️ 安装后必做：清掉 opencv-python，只留 headless
#   原因：insightface 的依赖里写死了 opencv-python（带 GUI 的完整版），
#         装它会把 opencv-python 一起拉进来，与上面显式声明的
#         opencv-python-headless 共用同一个 cv2/ 目录 —— 两者同装是
#         opencv 官方明确不推荐的组合，会出现 DLL 冲突 / 随机关闭 GUI 依赖。
#         本项目只绑 127.0.0.1 的本地服务、不开窗口，完整版没有任何用处。
#
#   验证（应只剩 headless，且 import cv2 正常）：
#     code\.venv\Scripts\pip list | findstr opencv
#     code\.venv\Scripts\python -c "import cv2, insightface; print(cv2.__version__)"
#
#   注意顺序：两个 opencv 包先一起卸掉再重装 headless。
#   直接只卸 opencv-python 会连带删掉 headless 也要用的 cv2/*.dll，导致 import cv2 失败。
#     code\.venv\Scripts\pip uninstall -y opencv-python opencv-python-headless
#     code\.venv\Scripts\pip install -i https://pypi.org/simple opencv-python-headless
#
#   本机已于 2026-10-04 执行完毕并验证通过（仅 opencv-python-headless 5.0.0.93，
#   onnxruntime 可用 provider = ['AzureExecutionProvider', 'CPUExecutionProvider']，确认无 GPU）。
